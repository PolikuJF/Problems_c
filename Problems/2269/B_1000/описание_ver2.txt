ОПИСАНИЕ ЗАДАЧИ
----------------------------------------
Дано a тестов. В каждом тесте:
  - Считывается b чисел.
  - Для каждого числа вычисляется его "судьба"
    при многократном применении операции:
        заменить число суммой квадратов его цифр.
  - Нужно посчитать количество пар чисел, которые
    приведут к одинаковому финальному состоянию
    за одинаковое количество шагов (с учётом
    периодичности для "несчастливых" чисел).

Финальные состояния:
  - 1 — "счастливое" число (приходит к 1)
  - 4 — "несчастливое" число (попадает в цикл
        4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4)

ИДЕЯ РЕШЕНИЯ
----------------------------------------
1. Для каждого числа вычисляем:
   - конечное состояние (1 или 4)
   - количество шагов до его достижения

2. Формируем ключ для группировки:
   - если состояние == 1  → ключ = -1
     (все "счастливые" числа эквивалентны)
   - если состояние == 4  → ключ = steps % 8
     (учитываем фазу цикла длины 8)

3. Считаем частоты ключей через unordered_map.

4. Для каждой группы размера cnt добавляем
   C(cnt, 2) = cnt * (cnt - 1) / 2 — количество
   пар в этой группе.

5. Суммируем все пары по всем группам.

ПОЧЕМУ ЦИКЛ ДЛИНЫ 8
----------------------------------------
Последовательность для "несчастливых" чисел:
  4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 → ...
Длина цикла = 8. Поэтому два числа с шагами s1 и s2
эквивалентны, если s1 ≡ s2 (mod 8).

ПОЧЕМУ КЛЮЧ -1 ДЛЯ "СЧАСТЛИВЫХ"
----------------------------------------
Все числа, приходящие к 1, ведут себя одинаково —
неважно, за сколько шагов они туда пришли. Любые два
таких числа образуют подходящую пару. Поэтому для
них используется один общий ключ.

Отрицательное значение -1 выбрано, чтобы не
пересекаться с ключами 0..7 для "несчастливых".
Можно было бы использовать любое число вне [0, 7],
например 8 или 100.

РАЗБОР КОДА
----------------------------------------

1) Функция count_operations(num)
   std::pair<int, int> count_operations(int num) {
       int steps = 0;
       while (num != 1 && num != 4) {
           int sum = 0;
           while (num > 0) {
               int d = num % 10;
               sum += d * d;
               num /= 10;
           }
           num = sum;
           ++steps;
       }
       return {num, steps};
   }

   - Пока число не равно 1 или 4:
       * Считаем сумму квадратов цифр.
       * Заменяем число на эту сумму.
       * Увеличиваем счётчик шагов.
   - Возвращаем пару: (конечное состояние, шаги).

   Отличие от предыдущей версии: используется
   одна переменная num вместо копии t. Это
   безопасно, потому что исходное значение
   больше не нужно после вычисления суммы.

2) main() — чтение и обработка
   int a;  std::cin >> a;
   while (a--) {
       int b;  std::cin >> b;
       std::unordered_map<int, long long> freq;

       for (int j = 0; j < b; ++j) {
           int x;  std::cin >> x;
           auto [state, steps] = count_operations(x);
           int key = (state == 1) ? -1 : (steps % 8);
           ++freq[key];
       }

       long long total = 0;
       for (auto& [key, cnt] : freq) {
           total += cnt * (cnt - 1) / 2;
       }

       std::cout << total << '\n';
   }

   - Считываем количество тестов a.
   - Для каждого теста считываем b.
   - Используем unordered_map<int, long long>
     для подсчёта частот ключей.
   - Для каждого числа вычисляем state и steps.
   - Формируем ключ: -1 для state == 1,
     steps % 8 для state == 4.
   - Увеличиваем счётчик для этого ключа.
   - После обработки всех чисел проходим по map
     и суммируем C(cnt, 2) для каждой группы.
   - Выводим total.

СЛОЖНОСТЬ
----------------------------------------
Для одного теста с b числами:
  - Вычисление count_operations: O(log num) на число
  - Работа с unordered_map: O(1) в среднем на число
  - Подсчёт пар: O(уникальных ключей) ≤ O(9)
Итого: O(b * log num) на тест.
Память: O(1) — map хранит не более 9 ключей
        (один для "счастливых" + 8 для фаз цикла).

ПРЕИМУЩЕСТВА ПЕРЕД ПРЕДЫДУЩЕЙ ВЕРСИЕЙ
----------------------------------------
1. Не нужна сортировка — O(b log b) заменено на O(b).
2. Не нужен vector пар — память O(1) вместо O(b).
3. Код короче и читаемее.
4. Использование structured bindings (C++17)
   делает код лаконичнее.

ПРИМЕР РАБОТЫ
----------------------------------------
Вход:
1
4
19 28 1 4

Число 19:
  1^2 + 9^2 = 82
  8^2 + 2^2 = 68
  6^2 + 8^2 = 100
  1^2 + 0^2 + 0^2 = 1
  → state = 1, steps = 4, key = -1

Число 28:
  2^2 + 8^2 = 68
  6^2 + 8^2 = 100
  1^2 + 0^2 + 0^2 = 1
  → state = 1, steps = 3, key = -1

Число 1:
  → state = 1, steps = 0, key = -1

Число 4:
  → state = 4, steps = 0, key = 0 % 8 = 0

freq после обработки:
  key = -1: cnt = 3
  key =  0: cnt = 1

total:
  -1: 3 * 2 / 2 = 3
   0: 1 * 0 / 2 = 0
  total = 3

Выход:
3

ЗАМЕТКИ И ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------
1. count_operations принимает int. Если числа
   могут быть больше 2^31 - 1, нужно заменить
   на long long.

2. Сумма квадратов цифр для int не переполнится:
   максимум для 10-значного числа ~ 10 * 81 = 810,
   что влезает в int.

3. Количество шагов не превышает ~20 для чисел
   до 10^9, так что int хватает.

4. long long для счётчиков частот обязателен:
   при b = 10^5 cnt может быть 10^5, и cnt * (cnt-1)
   может достигать ~10^10, что не влезает в int.

5. unordered_map с 9 ключами работает очень быстро,
   но можно заменить на обычный массив размером 9:
       long long freq[9] = {0};
       ...
       ++freq[key + 1];  // сдвиг, чтобы -1 → 0
   Это ещё быстрее, но менее наглядно.

6. Structured bindings (auto [state, steps] = ...)
   требуют C++17. Если компилятор старый,
   замените на:
       auto p = count_operations(x);
       int state = p.first;
       int steps = p.second;

ЗАМЕТКИ ПО ОПТИМИЗАЦИИ
----------------------------------------
- Замена unordered_map на массив из 9 элементов
  даст небольшой прирост скорости.
- Можно кэшировать результаты count_operations
  для повторяющихся чисел, но при b до 10^5
  это не обязательно.
- Если числа большие и их много, стоит
  использовать более быстрый ввод-вывод:
      std::ios_base::sync_with_stdio(false);
      std::cin.tie(NULL);
