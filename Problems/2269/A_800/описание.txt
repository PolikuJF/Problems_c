ОПИСАНИЕ ЗАДАЧИ
----------------------------------------
На вход подаётся n запросов. В каждом запросе даны
два числа a и b. Для каждой пары нужно вычислить
значение по формуле:

    ответ = 2^(a - b + 1) + 2 * (b - 1)

и вывести результат.

ИДЕЯ РЕШЕНИЯ
----------------------------------------
1. Для каждой пары (a, b) вычисляем показатель степени:
       k = a - b + 1

2. Вычисляем 2 в степени k с помощью битового сдвига:
       1LL << k
   Это быстрее и точнее, чем std::pow.

3. Прибавляем 2 * (b - 1).

4. Сохраняем результат в массив answers.

5. После обработки всех запросов выводим ответы
   по одному в строке.

ПОЧЕМУ ИСПОЛЬЗУЕТСЯ 1LL << k
----------------------------------------
Оператор << (битовый сдвиг влево) сдвигает двоичное
представление числа влево на k позиций. Это эквивалентно
умножению на 2^k.

Например:
    1LL << 0  =  1     = 2^0
    1LL << 1  =  2     = 2^1
    1LL << 2  =  4     = 2^2
    1LL << 3  =  8     = 2^3
    1LL << 10 = 1024   = 2^10

Важно: используется 1LL (long long), а не просто 1,
чтобы избежать переполнения при больших k. Если написать
1 << k, то при k >= 31 результат будет неверным, так как
int — 32-битный тип.

РАЗБОР КОДА
----------------------------------------

1) Чтение количества запросов
   int n;
   std::cin >> n;

2) Создание массива для ответов
   std::vector<long long> answers(n);
   Используем long long, потому что 2^k может быть
   очень большим числом (при k = 62 результат
   близок к пределу long long).

3) Обработка каждого запроса
   for (int i = 0; i < n; ++i) {
       long long a, b;
       std::cin >> a >> b;

       long long k = a - b + 1;
       answers[i] = (1LL << k) + 2 * (b - 1);
   }

   - Считываем a и b.
   - Вычисляем k = a - b + 1.
   - Считаем 2^k через 1LL << k.
   - Прибавляем 2 * (b - 1).
   - Сохраняем в массив.

4) Вывод результатов
   for (int i = 0; i < n; ++i) {
       std::cout << answers[i] << '\n';
   }
   Выводим каждый ответ на новой строке.

СЛОЖНОСТЬ
----------------------------------------
Время:  O(n) — один проход по всем запросам
Память: O(n) — храним массив ответов

МОЖНО ЛИ УЛУЧШИТЬ
----------------------------------------
Массив answers не обязателен — можно выводить ответ
сразу после вычисления:

    for (int i = 0; i < n; ++i) {
        long long a, b;
        std::cin >> a >> b;
        long long k = a - b + 1;
        std::cout << (1LL << k) + 2 * (b - 1) << '\n';
    }

Это сэкономит память (O(1) вместо O(n)), но лишит
возможности вывести все ответы разом в конце.
Для большинства задач оба варианта равнозначны.

ПРИМЕР РАБОТЫ
----------------------------------------
Вход:
3
5 3
4 1
6 2

Запрос 1: a=5, b=3
  k = 5 - 3 + 1 = 3
  2^3 = 8
  2 * (3 - 1) = 2 * 2 = 4
  ответ = 8 + 4 = 12

Запрос 2: a=4, b=1
  k = 4 - 1 + 1 = 4
  2^4 = 16
  2 * (1 - 1) = 0
  ответ = 16 + 0 = 16

Запрос 3: a=6, b=2
  k = 6 - 2 + 1 = 5
  2^5 = 32
  2 * (2 - 1) = 2
  ответ = 32 + 2 = 34

Выход:
12
16
34

ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------
1. Если k < 0 (то есть a - b + 1 < 0), то сдвиг
   влево на отрицательное число — это неопределённое
   поведение в C++. Скорее всего, по условию задачи
   a >= b, поэтому k >= 1. Но стоит проверить.

2. Если k >= 63, то 1LL << k переполнит long long
   (максимум ~9.2 * 10^18, то есть 2^63 - 1).
   Если по условию задачи ответ может быть больше,
   нужно использовать другой подход (например,
   вывод в виде строки или работа с big integers).

3. Тип long long гарантирует 64 бита. Для k до 62
   всё будет корректно.

ЗАМЕТКИ
----------------------------------------
- Формула 2^(a-b+1) + 2*(b-1) часто встречается
  в задачах на построение последовательностей,
  где нужно найти k-й элемент или сумму.
- Битовый сдвиг — стандартный приём для быстрого
  возведения двойки в степень.
