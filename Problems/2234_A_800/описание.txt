========================================
Описание программы
========================================

Задача: A. Евклид, последовательность, два числа

Назначение:
Программа обрабатывает t тестов. В каждом тесте задаётся
последовательность b длины n. Требуется определить, можно ли
переставить элементы этой последовательности так, чтобы она
стала последовательностью алгоритма Евклида для некоторых
целых положительных чисел x >= y. Если да — вывести эти x и y,
иначе — вывести -1.

Алгоритм работы:
1. Считать количество тестов t.
2. Для каждого теста:
   а) Считать n — размер последовательности.
   б) Считать n чисел в динамический массив arr.
   в) Отсортировать массив по убыванию.
   г) Проверить для всех i от 0 до n-3 условие:
          arr[i] % arr[i+1] == arr[i+2]
      Если хотя бы одно условие не выполнено — последовательность
      не может быть последовательностью Евклида, вывести -1.
   д) Если все условия выполнены, вывести arr[0] и arr[1] —
      первые два числа последовательности (x и y).
3. Освободить память.

Почему сортировка по убыванию:
Последовательность алгоритма Евклида обладает свойством:
    a1 >= a2 > a3 > a4 > ... > ak >= 0
(начиная со второго элемента строго убывает).
Поэтому единственно возможный порядок элементов — по убыванию.
Если после сортировки условие модуля не выполняется, значит,
никакая перестановка не даст нужную последовательность.

Разбор кода:
1. Подключение библиотек:
   - iostream — ввод-вывод
   - algorithm — sort
   - functional — greater<int>()

2. Ускорение ввода-вывода:
   ios_base::sync_with_stdio(false);
   cin.tie(nullptr);

3. Основной цикл while(t--):
   - Считывается n.
   - Выделяется динамический массив int *arr = new int[n].
   - Флаг flag = true.

4. Считывание элементов массива.

5. Сортировка:
   std::sort(arr, arr + n, std::greater<int>());
   Массив упорядочивается по убыванию.

6. Проверка условия Евклида:
   for (int i = 0; i < n - 2; i++) {
       if (arr[i] % arr[i + 1] != arr[i + 2]) {
           flag = false;
           break;
       }
   }
   Проверяем, что остаток от деления текущего элемента на
   следующий равен элементу через один.

7. Вывод результата:
   - Если flag == false → "-1".
   - Иначе → arr[0] и arr[1] через пробел.

8. Освобождение памяти:
   delete[] arr;

Сложность:
Время:  O(n log n) на один тест — из-за сортировки.
Память: O(n) — хранится массив из n элементов.

Пример работы:
Вход:
2
4
13 8 5 3
3
5 3 1

Тест 1:
Исходная последовательность: 13, 8, 5, 3
Сортировка по убыванию: [13, 8, 5, 3]
Проверка:
  i=0: 13 % 8 = 5 == 5 — верно
  i=1: 8 % 5 = 3 == 3 — верно
Флаг true → вывод: 13 8

Тест 2:
Исходная последовательность: 5, 3, 1
Сортировка по убыванию: [5, 3, 1]
Проверка:
  i=0: 5 % 3 = 2 != 1 — неверно
Флаг false → вывод: -1

Выход:
13 8
-1

Заметки:
- Для n = 2 цикл проверки не выполняется, флаг остаётся true,
  и выводятся два наибольших числа. Это корректно, так как
  любые два положительных числа x >= y образуют
  последовательность Евклида длины 2.
- Все входные числа положительны (b_i >= 1), поэтому деление
  на ноль невозможно.
- Вместо динамического массива new/delete можно было
  использовать std::vector<int> для безопасности и удобства.
- Переменная n имеет тип int, что соответствует ограничению
  n <= 100.
