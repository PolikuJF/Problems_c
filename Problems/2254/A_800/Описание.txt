========================================
Задача: 2254A - Прилив
Сложность: *800
Теги: реализация, сортировки
========================================

ОПИСАНИЕ ЗАДАЧИ
----------------------------------------
Даны три числа a, b, c. Нужно найти медиану (среднее
по величине число) и определить, какое расстояние
меньше: от медианы до максимума или от медианы
до минимума. Вывести меньшее из этих расстояний.

ИДЕЯ РЕШЕНИЯ
----------------------------------------
1. Находим максимум и минимум среди трёх чисел.
2. Находим медиану (среднее по величине число).
3. Сравниваем два расстояния:
     - от медианы до максимума (maxx - mid)
     - от медианы до минимума (mid - minn)
4. Выводим меньшее из них.

ПОЧЕМУ ЭТО РАБОТАЕТ
----------------------------------------
Прилив "поднимает" уровень воды. Чтобы уравнять
все три столба, нужно двигаться от крайних значений
к медиане. Выгоднее идти в ту сторону, где разница
меньше — это и есть ответ.

РАЗБОР КОДА
----------------------------------------

1) Функция midd(a, b, c)
   Возвращает медиану трёх чисел.
   Проверяет все случаи расположения чисел:
     - если b находится между a и c → return b
     - если a находится между b и c → return a
     - если c находится между a и c → return c

2) main()
   - Считываем количество тестов t
   - Для каждого теста:
       * Считываем a, b, c
       * maxx = максимум из трёх чисел (std::max({a,b,c}))
       * minn = минимум из трёх чисел (std::min({a,b,c}))
       * mid  = медиана (через функцию midd)
       * Сравниваем (maxx - mid) и (mid - minn)
       * Выводим меньшее значение

СЛОЖНОСТЬ
----------------------------------------
Время:  O(1) на один тест
Память: O(1)

ПРИМЕР РАБОТЫ
----------------------------------------
Вход:
1
1 2 3

Максимум: 3
Минимум:  1
Медиана:  2

maxx - mid = 3 - 2 = 1
mid - minn = 2 - 1 = 1

1 > 1? Нет → выводим maxx - mid = 1

Выход:
1

ЗАМЕТКИ
----------------------------------------
- Используется long long, чтобы избежать переполнения
  при больших входных числах.
- Подключён <algorithm> для std::max и std::min
  со списком инициализации.
- Функция midd написана вручную для наглядности.
  Альтернатива в одну строку:
      long long mid = a + b + c - maxx - minn;
