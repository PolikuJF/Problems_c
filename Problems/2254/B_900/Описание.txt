========================================
Задача: 2254B
Сложность: *900
Теги: два указателя, реализация, строки
========================================

ОПИСАНИЕ ЗАДАЧИ
----------------------------------------
Дана строка s длины n. Разрешается удалить ровно один
символ (или не удалять вовсе, если это не улучшает
результат). После удаления нужно посчитать, сколько
раз соседние символы совпадают, и вывести количество
"склеек" — то есть длину строки минус число совпадений
соседних символов.

Проще говоря: нужно минимизировать количество пар
одинаковых соседних символов, удалив один символ.

ИДЕЯ РЕШЕНИЯ
----------------------------------------
1. Ищем "выгодный" символ для удаления — такой, что
   после его удаления два его соседа окажутся разными.
   Это уменьшает количество совпадений.

2. Если такой символ найден:
   - удаляем его
   - больше ничего не делаем

3. Если такого символа нет:
   - ищем любой символ, у которого соседи отличаются
     от него самого (то есть s[i-1] != s[i] и s[i] != s[i+1])
   - удаляем его — это тоже может улучшить ситуацию

4. Считаем количество совпадений соседних символов
   в получившейся строке.

5. Ответ = длина строки минус количество совпадений.

ПОЧЕМУ ЭТО РАБОТАЕТ
----------------------------------------
Каждое совпадение соседних символов — это "лишний"
символ, который можно было бы убрать. Чем меньше
совпадений, тем "пестрее" строка. Удаляя один символ,
мы можем разорвать одну пару одинаковых соседей,
если правильно выбрать позицию.

РАЗБОР КОДА
----------------------------------------

1) Быстрый ввод-вывод
   std::ios_base::sync_with_stdio(false);
   std::cin.tie(NULL);
   Нужно для ускорения при больших входных данных.

2) Первый цикл (поиск "идеального" символа)
   for (int i = 1; i < n - 1; i++) {
       if (s[i-1] != s[i] & s[i] != s[i+1] & s[i-1] == s[i+1]) {
           s.erase(i, 1);
           count2--;
           break;
       }
   }
   Ищем позицию i, где:
     - s[i-1] != s[i]   (слева от i символ другой)
     - s[i]   != s[i+1] (справа от i символ другой)
     - s[i-1] == s[i+1] (соседи i равны между собой)
   Если нашли — удаляем s[i]. После удаления два
   одинаковых соседа "схлопнутся" в одного, и
   количество совпадений уменьшится.

3) Второй цикл (запасной вариант)
   if (count2 == 1) {
       for (int i = 1; i < n - 1; i++) {
           if (s[i-1] != s[i] & s[i] != s[i+1]) {
               s.erase(i, 1);
               break;
           }
       }
   }
   Если "идеальный" символ не найден, ищем любой
   символ, который отличается от обоих соседей,
   и удаляем его. Это тоже может помочь.

4) Подсчёт совпадений
   for (int i = 0; i < s.size() - 1; i++) {
       if (s[i] == s[i + 1]) {
           count++;
       }
   }
   Считаем, сколько раз соседние символы равны.

5) Вывод ответа
   std::cout << s.size() - count << '\n';
   Длина строки минус количество совпадений — это
   и есть искомое число.

СЛОЖНОСТЬ
----------------------------------------
Время:  O(n) на один тест
Память: O(n) — храним строку

ЗАМЕТКИ И ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------
1. В коде используется побитовое '&' вместо логического
   '&&'. В данном случае это работает, потому что
   сравнения возвращают 0 или 1, но лучше писать '&&' —
   это безопаснее и понятнее.

2. Переменная count2 инициализируется как 1 и
   уменьшается до 0, если символ был удалён в первом
   цикле. Это флаг "уже удалили символ".

3. Если строка состоит из одного символа (n = 1),
   циклы не выполнятся, count = 0, ответ = 1.
   Это корректно.

4. std::string::erase(i, 1) удаляет один символ
   на позиции i и сдвигает остальные влево.
   Размер строки уменьшается на 1.

ПРИМЕР РАБОТЫ
----------------------------------------
Вход:
1
5
aabba

Первый цикл:
  i=1: s[0]='a', s[1]='a', s[2]='b'
       s[0] != s[1]? Нет (a == a) → пропуск
  i=2: s[1]='a', s[2]='b', s[3]='b'
       s[1] != s[2]? Да
       s[2] != s[3]? Нет (b == b) → пропуск
  i=3: s[2]='b', s[3]='b', s[4]='a'
       s[2] != s[3]? Нет → пропуск

Первый цикл ничего не удалил.

Второй цикл (count2 == 1):
  i=1: s[0]='a', s[1]='a', s[2]='b'
       s[0] != s[1]? Нет → пропуск
  i=2: s[1]='a', s[2]='b', s[3]='b'
       s[1] != s[2]? Да
       s[2] != s[3]? Нет → пропуск
  i=3: s[2]='b', s[3]='b', s[4]='a'
       s[2] != s[3]? Нет → пропуск

Второй цикл тоже ничего не удалил.
Строка осталась "aabba".

Подсчёт совпадений:
  i=0: s[0]='a', s[1]='a' → совпадение, count=1
  i=1: s[1]='a', s[2]='b' → нет
  i=2: s[2]='b', s[3]='b' → совпадение, count=2
  i=3: s[3]='b', s[4]='a' → нет

count = 2
Ответ = 5 - 2 = 3

Выход:
3

ЗАМЕТКИ ПО УЛУЧШЕНИЮ
----------------------------------------
- Заменить все '&' на '&&' для читаемости.
- Переменную count2 можно заменить на bool flag.
- Функцию подсчёта совпадений можно вынести
  в отдельную функцию.
