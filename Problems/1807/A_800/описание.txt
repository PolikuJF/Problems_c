ОПИСАНИЕ ЗАДАЧИ
----------------------------------------
Дано t тестов. В каждом тесте подаются три целых числа a, b, c.
Нужно определить, какое арифметическое действие связывает
первые два числа с третьим:
  - если a + b == c, вывести '+'
  - иначе вывести '-'

ИДЕЯ РЕШЕНИЯ
----------------------------------------
Задача проверяет только одно условие: равна ли сумма
первых двух чисел третьему. Если да — это сложение,
иначе — вычитание (по условию других вариантов нет).

Алгоритм тривиален:
1. Считать количество тестов t.
2. Для каждого теста считать a, b, c.
3. Если a + b == c, вывести '+', иначе '-'.

ПОЧЕМУ ЭТО РАБОТАЕТ
----------------------------------------
По условию задачи гарантируется, что либо a + b == c,
либо a - b == c (или b - a == c, в зависимости от
формулировки). В данном коде проверяется только
сумма. Если она не равна c, автоматически выводится '-'.
Это корректно, если в задаче ровно два варианта ответа.

РАЗБОР КОДА
----------------------------------------

1) Подключение и константа
   #include <iostream>
   using namespace std;
   const int MAXN = 1005;

   Константа MAXN не используется в коде.
   Это лишняя строка, её можно удалить.

2) Ускорение ввода-вывода
   ios_base::sync_with_stdio(false);
   cin.tie(nullptr);
   Нужно для быстрой работы при большом t.

3) Основной цикл
   int t;
   std::cin >> t;
   while(t--) {
       int a, b, c;
       std::cin >> a >> b >> c;
       if (a + b == c) {
           std::cout << '+' << '\n';
       } else {
           std::cout << '-' << '\n';
       }
   }

   - Считываем t.
   - Для каждого теста считываем три числа.
   - Проверяем условие a + b == c.
   - Выводим соответствующий символ и перевод строки.

СЛОЖНОСТЬ
----------------------------------------
Время:  O(t) — один проход по всем тестам.
Память: O(1) — не храним ничего лишнего.

ПРИМЕР РАБОТЫ
----------------------------------------
Вход:
3
1 2 3
5 5 9
10 20 30

Тест 1: 1 + 2 = 3 → '+'
Тест 2: 5 + 5 = 10 ≠ 9 → '-'
Тест 3: 10 + 20 = 30 → '+'

Выход:
+
-
+

ЗАМЕТКИ И ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------
1. Переменная MAXN не используется. Удалите её.

2. Если по условию задачи возможны оба варианта
   (и сложение, и вычитание), то одной проверки
   a + b == c недостаточно. Нужно также проверять
   a - b == c или b - a == c. Уточните условие.

3. Тип int подходит, если числа не превышают 2*10^9.
   Если могут быть больше — используйте long long.

4. Для вывода одного символа можно использовать
   std::cout << '+' << '\n'; это нормально.
   Можно также применить putchar('+'); putchar('\n');
   для ещё большей скорости, но это избыточно.

ЗАМЕТКИ ПО ОПТИМИЗАЦИИ
----------------------------------------
- Удалить неиспользуемую константу MAXN.
- Если тестов очень много, можно использовать
  буферизованный вывод, но cout с sync_with_stdio(false)
  и так достаточно быстр.
- Проверку можно записать короче:
      std::cout << (a + b == c ? '+' : '-') << '\n';
